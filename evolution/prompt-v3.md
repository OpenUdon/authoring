# Prompt V3 - Adaptive Evidence-Grounded Authoring

Replace the fixed 20-attempt, one-question-at-a-time iCoT design with a
dependency-aware interview modeled on adaptive memory-bank initialization.

Add `authoring.interview.v1` with nodes, a unified public evidence ledger,
answers, and structured deferrals. Validate identifiers, references, cycles,
statuses, transitions, and deferral completeness. Compute every
dependency-ready open node as one deterministic frontier.

Consolidate generic, runtime-bound, and interactive iCoT onto one round engine.
Show the complete numbered frontier before collecting answers, apply all
answers together, then normalize and autosave once. Remove the breadth ceiling
and stop after three consecutive rounds without state/readiness progress.
Retain full, normal, and fast default behavior. Store concise public rationale
only, never hidden model chain-of-thought.

Keep product prompts, API source discovery, workflow semantics, artifacts,
provider clients, and execution downstream. Keep Ramen unchanged and migrate
OpenUdon's product wires separately.
