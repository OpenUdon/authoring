# Result V2

Authoring's roadmap now starts with Evidence-backed durable primitives, then
adds public session/transcript, prompt/replay, lifecycle, structured-output,
progressive-loop, runtime-adapter, decision-evidence, readiness, repair,
agent-result, report, scorecard, and prompt-safe context contracts. OpenUdon
adoption is split into two phases before Ramen adapter adoption, followed by
cross-repo compatibility, public API stabilization, and fake-runtime examples.
